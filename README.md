# File Integrity Checker

A Python-based cybersecurity tool that generates SHA-256 hashes to verify file integrity and detect file modifications.

## Features
- Generates SHA-256 hashes
- Detects file changes
- Demonstrates cryptographic hashing
- Beginner-friendly cybersecurity project

## Technologies Used
- Python
- hashlib
